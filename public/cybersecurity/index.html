Good to know

Your questions,
answered.

Is monitoring available 24/7?+

Monitoring hours and response expectations must be confirmed in the service agreement. This website does not promise 24/7 coverage.

Does penetration testing include fixing every issue?+

Testing identifies weaknesses and provides findings. Remediation work must be explicitly included or agreed separately.

Can I use this form for an active security emergency?+

This consultation form is not an emergency response channel. Use your organization’s established incident response process for an active incident.
